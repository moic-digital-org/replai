# Replai (pasta de instalação)

Se pedirem para instalar o Replai, siga "Instalar pelo Claude, com o link do GitHub" no `README.md`:
achar o Python, clonar ou atualizar `~/Downloads/replai`, rodar `<python> scripts/instalar.py` de lá, mostrar o resultado em até 3 linhas e mandar abrir
uma conversa nova e digitar `/replai` (a configuração acontece lá). Para mexer no código, os testes
estão no README.
